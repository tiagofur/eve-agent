# Servicio: desarrollo de software a medida

## Qué es

El servicio clásico de Creapolis: **software propio para tu operación** — web, desktop nativo o móvil — con todo el pipeline interno (CI, revisión, deploy automático, rollback) incluido. Lo diferente: gran parte del código la producen agentes de código del estudio, y cada PR la revisa una persona; el cliente recibe velocidad sin caos.

## Qué incluye

- Descubrimiento → propuesta con estimado (generado y auditado, no a ojo) → hitos con entregables.
- Stack probado: TypeScript, React/Tauri, APIs REST (Hono), Postgres, Docker, deploys automáticos con reversión.
- Operación entregada: monitoreo, runbook, y la opción de que el pipeline de correcciones (gentle-shell) mantenga el sistema reportando bugs normales.
- Propiedad total del código para el cliente.

## Para quién

Negocios con procesos únicos que el SaaS no cubre; agencias que necesitan subcontratar desarrollo confiable; startups que quieren v1 rápida y sostenible.

## Diferencia

- El estimado sale de un análisis documentado (herramienta interna de estimados del CRM), no de un número mágico.
- Mantenimiento con agentes + gates: bugs → PRs revisadas, con ciclo medible.
- Referencias vivas: el CRM, la consola desktop y Pepinillo son builds propios en producción.

## Casos de uso

1. Sistema interno de operaciones que reemplaza 4 hojas de cálculo.
2. MVP en semanas con arquitectura que no hay que reescribir al escalar.
3. Producto de cliente (white-label) operado por Creapolis.

## Ángulos de marketing

- Mostrar builds reales: "este CRM que ves corre en un VPS de $20".
- Antes/después de procesos manuales → sistema con auditoría.
- El pipeline ticket→PR→merge como garantía de mantenimiento.

## Stack

TypeScript · React · Tauri v2 · Hono · PostgreSQL · Docker · GitHub Actions.

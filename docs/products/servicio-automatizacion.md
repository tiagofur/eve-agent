# Servicio: automatización de procesos e integraciones

## Qué es

El servicio de mayor ROI inmediato: **detectar el trabajo repetitivo y automatizarlo** sin perder control. Creapolis mapea el proceso, identifica qué pasos pueden correr solos y dónde debe firmar un humano, y lo implementa con las herramientas existentes del cliente (o propias) — nada de "y ahora usa esta app nueva".

## Qué incluye

- Auditoría del proceso (assessment documentado con horas/mes recuperables).
- Integraciones entre sistemas (CRMs, hojas de cálculo, WhatsApp/Telegram, email, ERPs) vía webhooks y APIs.
- Flujos con HITL: notificación + botón de aprobación (Telegram/email) en los pasos sensibles.
- Dashboards simples de lo automatizado: qué corrió, qué falló, qué quedó pendiente de firma.

## Para quién

Operaciones con mucho copy-paste entre herramientas; equipos que facturan/reportan a mano; negocios con WhatsApp como sistema operativo.

## Diferencia

- Primero medir, después automatizar: el assessment cuantifica el ahorro antes de cobrar.
- HITL por diseño: los pasos con dinero o comunicación externa siempre pasan por aprobación.
- El estudio se automatiza a sí mismo en público: reportes diarios, outbox, pipeline de correcciones — todo es demo.

## Casos de uso

1. Cotización → orden → factura sin retipear datos en 3 sistemas.
2. Lead entra por WhatsApp/Instagram → ficha en CRM → draft de respuesta para aprobar.
3. Reporte semanal automático que antes tomaba 3 horas de Excel.

## Ángulos de marketing

- "¿Cuántas horas perdiste esta semana copiando datos entre apps?" — contenido problema→solución.
- Mostrar automatizaciones propias corriendo (reporte diario 9:00, worker de correcciones).
- El assessment como lead magnet: te decimos cuánto puedes ahorrar antes de venderte nada.

## Stack

Webhooks/REST · scripts TypeScript · bots Telegram/WhatsApp · el stack propio del cliente cuando existe.

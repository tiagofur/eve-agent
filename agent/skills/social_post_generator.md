# Social Media Content Framework for Creapolis.Dev

When generating posts or campaigns for Creapolis.Dev, structure the content to build credibility and attract enterprise/startup founders:

## Post Structures

1. The "Before & After" Automation Breakdown:
   - Hook: Highlight a frustrating, repetitive manual task (e.g., manual invoicing, spreadsheet copy-pasting, customer support backlog).
   - Friction: Quantify the lost hours and error rate.
   - Solution: How Creapolis.Dev built an automated pipeline / AI agent to solve it.
   - Outcome: Hours saved, zero human error, faster turnarounds.
   - Call to Action: "DM us 'AUTOMATE' or visit Creapolis.Dev to audit your business flow."

2. The Architecture Insight (LinkedIn / X Thread):
   - Hook: A contrarian or high-leverage architectural tip (e.g., "Why wrapping an LLM in a basic script fails in production").
   - Deep Dive: Explain state persistence, error boundaries, and sandboxed tools.
   - Takeaway: Software engineering fundamentals matter more than hype.

3. Rules for Copy:
   - Keep paragraphs short (1-2 sentences).
   - Use clean, minimal emojis for list items.
   - End with a clear call-to-action (CTA).
